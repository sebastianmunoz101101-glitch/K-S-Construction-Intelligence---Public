## LinkedIn project description

I built a Python/SQL construction-estimating and KPI workflow from private real-world records from my family’s construction business. The project turns messy quotes, supplier estimates, invoices, and project notes into structured analysis for supplier savings, benchmark price variance, payment structure, change-scope tracking, reconciliation controls, and profitability/ROI metric governance.

The public GitHub repo uses synthetic demo rows for privacy. Private source records were used to design the workflow and validate KPI categories, but raw customer records, addresses, invoices, exact job totals, and actual job-cost dollar amounts are not public.

Core tools: Python, pandas, CSV data modeling, cost modeling, KPI definitions, validation metrics, Streamlit prototype.
