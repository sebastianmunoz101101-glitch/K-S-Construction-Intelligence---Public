# Public Portfolio Privacy Policy

This repository is a public portfolio version of a private business analytics project.

## What is not included

This repo does not include:

- raw source images
- invoices
- contracts
- customer names
- customer addresses
- phone numbers
- emails
- exact private job totals
- exact private material receipts
- actual K&S job-cost dollar records
- internal payroll, overhead, tax, owner-pay, or accounting records

## What is included

This repo includes:

- Python code
- KPI formulas
- synthetic demo CSV rows
- synthetic demo JSON output
- public-safe percentage findings
- validation and metric-governance notes

## Why synthetic data is used

The project was built from private construction records, but public release uses synthetic demo rows to avoid exposing client information or private business financials. The public files demonstrate workflow structure, calculations, validation logic, and reporting concepts without publishing sensitive records.

## Interview explanation

The public GitHub repo uses synthetic demo rows for privacy. Private source records were used to design the workflow and validate KPI categories, but raw customer records, addresses, invoices, exact job totals, and actual job-cost dollar amounts are not public.
