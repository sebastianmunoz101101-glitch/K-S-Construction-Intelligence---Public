# v1 Feature Scope

## Included in public v1

- Structured CSV input
- Material/labor cost calculation
- Waste factor
- Overhead and profit markup
- Missing-price and missing-quantity flags
- Estimate CSV output
- Job-level summary output
- Historical evaluation script using synthetic demo rows
- Streamlit demo interface
- Resume/LinkedIn/GitHub wording
- Privacy-safe public data policy

## Kept private

- Raw screenshots
- OCR outputs from private source images
- Customer invoices/contracts
- Client names and addresses
- Exact private job totals
- Actual K&S job-cost dollar records
- Internal payroll, overhead, tax, or accounting records

## Future v2 options

- OCR extraction from new permission-cleared documents
- Dashboard screenshots
- SQLite schema
- Unit tests for KPI formulas
- Optional Streamlit Cloud deployment using synthetic data only
- Private internal version with full job-cost records

These are v2 items. Do not delay v1 job applications for them.
